계정 삭제 안내

폴겟(Forget) 계정은 앱 안에서 직접 삭제할 수 있습니다. 별도의 문의나 승인 절차 없이 즉시 처리됩니다.

앱에서 계정을 삭제하는 방법

  1. 폴겟 앱을 열고 로그인합니다.
  2. 홈 화면 오른쪽 위의 설정(프로필)으로 이동합니다.
  3. 회원 탈퇴를 누릅니다.
  4. 확인 창에서 영구 삭제를 누르면 즉시 탈퇴됩니다.

삭제되는 데이터

탈퇴 시 다음 데이터가 즉시 영구 삭제되며 복구할 수 없습니다.

  1. 계정 정보(이메일 주소, 로그인 정보)
  2. 저장한 모든 항목(링크, 글, 사진, 메모)과 첨부 이미지
  3. 검색 기록 및 앱 사용 기록

서버에 별도로 보관되는 데이터는 없으며, 법령상 보존 의무가 있는 데이터도 없습니다.

앱에 접근할 수 없는 상황이라면 가입하신 이메일로 forgetappkr@gmail.com 에 계정 삭제를 요청해 주세요. 확인 후 처리해 드립니다.
