HOW IT WORKS

기억하려 하지 말고,
흐름대로 사용하세요.

폴겟의 핵심은 새로운 정리 습관을 강요하지 않는 것입니다.

  1. 01

    지금 보던 것을 저장합니다

    웹페이지, SNS 게시물, 텍스트, 사진을 공유 메뉴나 앱에서 바로 저장합니다.

  2. 02

    폴겟이 내용을 이해합니다

    AI가 콘텐츠를 읽고 7개 카테고리로 분류하며, 태그와 요약을 자동으로 생성합니다.

  3. 03

    기억나는 표현이나 음성으로 찾습니다

    정확한 파일명이나 단어를 몰라도 됩니다. 뜻으로 찾는 시맨틱 검색과 음성 검색을 한국어·영어로 사용할 수 있습니다.

  4. 04

    필요한 순간 다시 확인합니다

    리마인드와 핀 기능으로 저장한 정보를 실제 행동으로 연결합니다.

어떤 내용을 저장할 수 있나요?

링크, 텍스트 메모, 사진과 스크린샷을 저장할 수 있습니다. 다른 앱의 공유 메뉴를 통한 빠른 저장도 지원합니다.

정확한 제목이나 단어를 몰라도 검색할 수 있나요?

네. 시맨틱 검색으로 정확한 단어가 일치하지 않아도 뜻이 비슷한 저장물을 찾습니다. 텍스트뿐 아니라 마이크로 말해서 검색할 수 있고, 한국어·영어를 모두 지원합니다.

로그인은 어떤 방식을 지원하나요?

Apple 로그인, 카카오 로그인, 이메일 가입을 지원합니다.

다크모드와 언어 설정을 지원하나요?

네. 다크모드를 지원하며 앱은 한국어와 영어로 제공됩니다.

iPhone과 Android에서 모두 사용할 수 있나요?

iOS와 Android를 동일한 React Native·Expo 기반으로 개발하고 있으며, 현재 App Store 출시를 우선 준비하고 있습니다.

AI가 저장한 콘텐츠를 어떻게 처리하나요?

저장 콘텐츠의 자동 분류, 태그, 요약과 의미 기반 검색을 제공하는 데 필요한 범위에서 AI 서비스를 이용합니다. 자세한 처리 위탁 내용은 개인정보처리방침에서 확인할 수 있습니다.

가격은 어떻게 되나요?

출시 전 최종 가격 정책을 확정해 앱과 공식 홈페이지에서 투명하게 안내할 예정입니다.
